# 🏠 Real Estate Website

## 📌 Description
Website bất động sản cho phép người dùng đăng tin, tìm kiếm và quản lý bất động sản.

## 🚀 Tech Stack
- Frontend: Next.js, CSS Modules
- Backend: NestJS
- Database: (MySQL / PostgreSQL)

## ✨ Features
- User đăng bài bất động sản
- Lưu tin yêu thích
- Quản lý tin đã đăng
- Admin dashboard (CRUD)

## 📦 Installation
```bash
npm install
npm run dev
